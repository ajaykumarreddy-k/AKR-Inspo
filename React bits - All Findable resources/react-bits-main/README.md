An open-source collection of high-quality, animated, interactive, and customizable React UI components built with Tailwind CSS, Framer Motion / Motion, Three.js, GSAP, and OGL.

## Tech Stack

- **Core**: React 19, Vite
- **Styling**: Tailwind CSS
- **Animation**: Motion, GSAP, Three.js / React Three Fiber, OGL

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation & Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
```
