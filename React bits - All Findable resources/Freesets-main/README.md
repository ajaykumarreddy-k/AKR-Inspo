A curated collection of developer and designer resources, tools, icons, backgrounds, and libraries organized for quick exploration.

## Tech Stack

- **Framework**: SvelteKit
- **Styling**: Tailwind CSS
- **Bundler**: Vite

## Getting Started

The web application source code is located in the `source-web/` directory.

### Prerequisites

- Node.js 18+
- npm

### Installation & Local Setup

```bash
# Navigate to web source directory
cd source-web

# Install dependencies
npm install

# Run development server
npm run dev
```

Open `http://localhost:5173` in your browser.

### Building for Production

```bash
cd source-web
npm run build
npm run preview
```
